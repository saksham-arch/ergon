# ARTEMIS — Prototype assets

This is a noncommercial design concept using fictional job listings. No real employers or workers are represented. Work cards and reports stay in browser storage; sample hiring requests last only for the current visit.

## Original cinematic world

The animated Sisyphus, Hephaestus, Hermes, and Athena figures, opening gates, temples, olive trees, water, job stones, particles, and stage architecture are original procedural geometry created for this prototype in Three.js. The figures are stylized contemporary interpretations, not scans of historical sculptures.

The Hesperides garden is an artistic reference to Greek mythology. Visual research: https://www.metmuseum.org/art/collection/search/248092

## Artwork

Sisyphus, Hephaestus, Hermes, and Athena: generated with OpenAI image generation for this project. These are contemporary mythology-inspired interpretations, not archival images of historical artworks. Prompts retained in the workspace under `assets/greek-cards/prompts.json`.
